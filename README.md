# Amazon Ranking Tracker (亚马逊产品排名追踪工具)

## 📋 项目简介

基于 AI 辅助开发的亚马逊产品排名自动追踪工具。通过 Selenium 自动化浏览器，模拟真实用户搜索行为，自动抓取指定产品在特定关键词搜索结果中的广告位 (Sponsored) 和自然位 (Organic) 排名。

## 🎯 核心痛点

亚马逊卖家需要持续监控自家产品在目标关键词下的搜索排名表现，包括：
- 自然排名位置（不上广告时的免费流量入口位置）
- 广告排名位置（付费推广后的展示位置）
- 产品在不同关键词下的可见度
- 排名随时间的波动趋势

手动搜索记录效率极低且无法批量操作，本项目通过自动化手段一键完成多关键词、多产品的排名追踪。

## 🔄 核心逻辑流

```
1. 配置阶段
   设置关键词列表、目标 ASIN、最大查询页数、配送邮编
   
2. 自动化执行
   启动 Edge 浏览器 → 设置美国邮编 10010 → 
   逐个搜索关键词 → 逐页扫描搜索结果（最多 7 页）→
   匹配目标 ASIN → 识别广告位/自然位 → 
   记录位置数据
   
3. 数据输出
   生成格式化的 Excel 报告，包含：
   - 关键词维度
   - 广告位页码及位置区间（上/中/下部）
   - 自然位页码及位置区间
   - 对应 ASIN
   - 异常备注
```

## ✨ 主要特性

| 特性 | 说明 |
|------|------|
| **批量关键词** | 一次性处理 10+ 个关键词 |
| **多 ASIN 追踪** | 最多支持 100+ 个产品 ASIN 同时监控 |
| **广告位精准识别** | 多维特征探测（CSS 类名 + 标签属性 + 语义标签） |
| **反爬绕过** | 自动化检测屏蔽、随机延迟、无痕模式 |
| **自动翻页** | 最高 7 页深度扫描，自动翻页 |
| **Excel 输出** | 格式化的排名报告，含页码和位置区间 |
| **断点续存** | 每处理完一个关键词自动保存，避免崩溃丢数据 |

## 🛠 技术栈

## 🚀 使用方法

### 前置条件

1. 安装 Python 3.x
2. 安装依赖：
   ```bash
   pip install selenium openpyxl
   ```
3. 下载与你的 Edge 浏览器版本匹配的 [Edge WebDriver](https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/)
   - 放入 `EDGEdriver/` 目录
   - 或修改代码中 `EDGE_DRIVER_PATH` 路径

### 运行

1. 修改目标 Python 文件顶部的配置区域：
   - `KEYWORDS_LIST` - 要搜索的关键词
   - `YOUR_ASIN_LIST` - 你的产品 ASIN 列表
   - `RESULT_FILE` - 输出 Excel 文件名（可选）
2. 运行脚本：
   ```bash
   python gemini.py
   ```
3. 程序会自动打开 Edge 浏览器，依次搜索所有关键词并记录排名
